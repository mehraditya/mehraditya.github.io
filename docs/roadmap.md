# Long-Term Vision

The repository should become

A notebook.

A publishing platform.

A knowledge archive.

Not a portfolio.

The website should grow naturally with years of reading and writing.

Adding content should become easier over time.

Adding features should become rarer over time.

The interface should become quieter as the notebook becomes richer.
