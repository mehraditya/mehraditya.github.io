# Design Principles

> "The interface should disappear. The thinking should remain."

---

## Why this exists

This repository is not a portfolio.

It is not a blog.

It is not a landing page.

It is a publishing platform.

A public notebook documenting research, engineering, and long-form writing.

Everything in this repository exists to improve reading.

---

# Philosophy

The website should feel calm.

Not empty.

Not minimal for the sake of minimalism.

Calm.

The interface should never compete with the content.

Readers should remember the ideas.

Not the UI.

---

# Reading First

We optimize for people willing to spend twenty minutes reading.

Not twenty seconds browsing.

Every page should reward attention.

Every design decision should encourage focus.

---

# Typography

Typography is the interface.

Whitespace is the second interface.

Motion is the third.

Everything else is implementation.

Hierarchy should emerge naturally from

- font size
- spacing
- rhythm
- alignment

Never from decorative UI.

---

# Whitespace

Whitespace is not empty.

Whitespace creates rhythm.

Whitespace creates confidence.

Whitespace creates emphasis.

When unsure,

remove elements before reducing whitespace.

---

# Grid

Everything aligns.

Margins are intentional.

Paragraph widths are intentional.

Line lengths are intentional.

Nothing should feel "approximately positioned."

Every page follows the same invisible geometry.

---

# Motion

Motion exists to explain.

Never to entertain.

Animations should quietly reinforce continuity.

They should never interrupt reading.

---

# Color

Color supports reading.

It does not define the brand.

Muted colors.

Paper.

Ink.

Blue-grey.

Soft dividers.

Selection color is intentional.

Nothing is accidental.

---

# Components

Components are implementation details.

Readers should never notice them.

If typography and spacing solve a problem,

another component is unnecessary.

Avoid cards.

Avoid decoration.

Avoid unnecessary containers.

---

# Content

There are only two forms of content.

Research Notes

and

Writings.

Nothing else.

Research Notes document understanding.

Writings document synthesis.

Keep these separate.

---

# Publishing

Write privately.

Publish deliberately.

The website is the publishing layer.

Not the thinking layer.

Thinking happens elsewhere.

---

# Craftsmanship

Small details matter.

Selection color.

Line height.

Paragraph spacing.

Margins.

Animation timing.

Hover states.

The accumulation of thoughtful decisions creates quality.

---

# Standard

The goal is not to impress visitors.

The goal is to earn their attention.

When readers leave,

they should remember the writing,

not the website.
