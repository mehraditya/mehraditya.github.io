## Why this fixture exists

The system is meant to accept a note with nothing but frontmatter and a body, and render it as a chapter in the index plus a structured article. This fixture is the proof that the plumbing works: the title is read from the frontmatter, the date formats, the tags resolve, and the related link points at another note.

Nothing here is written to be persuasive. It is written to be counted, so that the vertical rhythm of several paragraphs, a list, a quotation and a code block can be judged side by side.

## Figures and layout tiers

Figures are the reason the reading column is not the same width as the article. A figure can sit at the reading measure, step out to the wide tier, or take the full article width and break the column deliberately.

### The three tiers

The author expresses only intent, never CSS. Choosing a variant in the content file is the entire authoring surface, and the presentation is handled in one place.

## Quotes, code and lists

A list survives the trip through the layout unchanged:

- the accent colour is scoped to this section of the site

A short code sample holds the wider tier so it does not wrap early:

```python
def progress(scroll_top, article_top, article_height, viewport):
    span = max(1, article_height - viewport)
    return min(1.0, max(0.0, (scroll_top - article_top) / span))
```
